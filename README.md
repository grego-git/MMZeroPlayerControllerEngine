# Meagman Zero Player Controller Engine
## About
I just finished playing Megaman Zero and was itchin to implement a player controller with a similar dash and wall jump mechanic. I turned it into a very samll level that has a boss at the end.
## Controls

| Action          | Keyboard Input          | Controller Input                           |
| :-------------: | :---------------------: | :----------------------------------------: |
| Move Left/Right | A/D                     | D-Pad/Left Stick                           |
| Jump            | Space/Left Mouse Button | Bottom Face Button (× Playstation; A XBOX) |
| Dash            | Left Ctrl               | Left Face Button (□ Playstation; A XBOX)   |
| Pause           | Escape                  | Pause Button                               |
